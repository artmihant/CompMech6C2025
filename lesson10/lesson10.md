# Занятие 10. Технологии ускорения и распараллеливания вычислений в Python

## План семинара

### 1. Введение в оптимизацию кода
- Зачем нужна оптимизация? Понятие "бутылочного горлышка" (bottleneck).
- Инструменты для профилирования:
  - `%time` и `%timeit` в Jupyter для простых замеров.
  - Модуль `cProfile` для детального анализа времени выполнения функций.
- Важность правильных алгоритмов перед преждевременной оптимизацией.

### 2. Векторизация и `Numpy`
- Повторение концепции векторизации.
- Примеры, где `Numpy` дает кратное ускорение по сравнению с циклами Python.
- Ограничения `Numpy`: создание промежуточных массивов, потребление памяти.

### 3. Ускорение на CPU с `Numba`
- Концепция Just-In-Time (JIT) компиляции.
- Декоратор `@jit` и его режимы (`nopython=True` vs. object mode).
- Практическое применение `@njit` для ускорения числодробильных функций.
- Автоматическое распараллеливание циклов с `parallel=True`.
- Понятие о Global Interpreter Lock (GIL) и как `Numba` его обходит.

### 4. Основы вычислений на GPU (GPGPU)
- Что такое GPGPU и зачем это нужно?
- Краткий обзор архитектуры CUDA:
  - **Хост** (CPU) и **устройство** (GPU).
  - Иерархия потоков: **Grid** -> **Block** -> **Thread**.
  - Иерархия памяти: глобальная, разделяемая, локальная.
- Основная парадигма: массовый параллелизм (SIMT - Single Instruction, Multiple Threads).

### 5. `Numba.cuda` для вычислений на GPU
- Написание **ядер** (kernels) — функций, выполняемых на GPU.
- Запуск ядер с указанием конфигурации грида и блоков.
- Управление памятью:
  - `cuda.to_device()`: копирование данных с CPU на GPU.
  - `copy_to_host()`: копирование результатов обратно на CPU.
- Пример "Hello, World!" на `numba.cuda`: параллельное сложение векторов.

## Сюжет урока: Оптимизация вычисления фрактала Мандельброта

На примере этой классической задачи мы пройдем все этапы оптимизации:

1.  **Наивная реализация**: чистый Python с вложенными циклами. Профилируем и находим узкие места.
2.  **Векторизация**: использование `Numpy` для работы с комплексной плоскостью как с массивом.
3.  **Ускорение на CPU**: применение `@njit` к функции, вычисляющей итерации для одной точки.
4.  **Распараллеливание на CPU**: добавление `parallel=True` для обработки нескольких точек одновременно.
5.  **Перенос на GPU**:
    - Написание CUDA-ядра, где каждый поток вычисляет цвет одного пикселя.
    - Управление памятью GPU для хранения результирующего изображения.
6.  **Сравнительный анализ**: построение графика времени выполнения для каждого из подходов. Демонстрация многократного ускорения при переходе на GPU.
