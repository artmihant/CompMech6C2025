Нужно создать игру "Mario" на  Python.

Пусть в игре для простоты будет пока-что один уровень. Перед началом уровня будет показано меню:
- старт
- info

1. При нажатии на старт запускается уровень. В верхнем правом углу находится кнопка паузы - при нажатии на нее игровой процесс приостанавливается, кнопка паузы меняется на "play".

Спрайты: используй unicode смайлики в качестве спрайтов для главного героя, блоков, врагов, препятствий.

Управление (клавиатура):
- стрелка влево
- стрелка вправо
- пробел - прыжок

Нужно будет учитывать коллизии персонажа с блоками, врагами. В случае столкновения - начинать уровень сначала.
