# Свободное баллистическое падение по параболе 2D

## Описание задачи

Скрипт моделирует движения тела, брошенного под углом к горизонту, строит семейство траекторий для разных начальных скоростей и углов, а также анимирует несколько траекторий.

Для численного интегрирования вертикальной составляющей скорости/координаты используется метод Рунге--Кутты 4-го порядка (RK4). По x-координате движение учитывается явно (v_x = const).

Также реализовано численное нахождение угла, дающего максимальную дальность, методом золотого сечения, и сравнение с аналитическим решением (оптимум -- 45 градусов).

## Основные функции

Файл содержит следующие важные функции:

1. simulate_projectile(v0, alpha, g, dt, max_time)

Численно моделирует движение тела методом RK4 (начало в (x,y)=(0,0)) при начальной скорости v0 и угле alpha.
dt -- шаг интегрирования
Функция возвращает (xs, ys, x_ground) -- массивы координат и x-координата попадания в землю (y=0).

2. analytic_range(v0, alpha, g)

Функция возвращает аналитическую дальность при отсутствии сопротивления воздуха по формуле R = v0^2 * sin(2*alpha) / g.

3. numeric_range(v0, alpha, dt)

Вспомогательная функция, вызывающая simulate_projectile и возвращающая численную дальность x_ground.

4. golden_section_max(v0, a_low, a_high, tol, max_iter, dt)

Фукнция с помощью метода золотого сечения ищет угол alpha на отрезке [a_low, a_high], при котором численная дальность максимальна.
Возвращает (alpha_opt, R_opt) -- найденный угол и соответствующая дальность.

Скрипт строит два рисунка:

- семейство траекторий для нескольких v0 и нескольких углов; поверх этого рисуется аналитическая траектория для v0 = 10 и alpha = 45 градусовp;
- анимация полёта для набора углов при фиксированной v0.

Производятся сравнения аналитического и численного оптимумов для v0_opt и строятся соответствующие траектории и точки приземления на графике.

Ожидаемый результат работы программы: метод золотого сечения должен вернуть угол, близкий к 45 градусам и численную дальность, близкую к аналитической.
