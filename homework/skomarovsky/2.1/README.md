# Double Pendulum 2

Python‑скрипт для:
- построения двойных маятников для больших начальных углов
- анализа траекторий в зависимости от начальных данных

Файл: `double_pendulum_2.py`

## Возможности
- Численное интегрирование уравнений двойного нелинейного маятника методом RK4 и RK45
- Анимация набора маятников с разными начальными условиями
- Построение траекторий 

## Модель
Рассматривается двойной маятник:
- Состояние x = (phi1,phi2,psi1,psi2)
- Уравнения движения:
 - det = L^2 * L2^2 * (1 + sin(phi1 - phi2)^2)
 - b1 = -L1 * L2 * psi2^2 * sin(phi1 - phi2) - 2 * g * L1 * sin(phi1)
 - b2 = L1 * L2 * psi1^2 * sin(phi - phi2) - g * L2 * sin(phi2) 
 -
 - phi1' = psi1
 - phi2' = psi2
 - psi1' = (b1 * L2^2 - b2 * L1 * L2 * cos(phi1-phi2)) / det
 - psi2' = (b2 * 2 * L1^2 - b1 * L1 * L2 * cos(phi1-phi2)) / det

Задаётся начальное положение (80 градусов, -20 градусов, 0, 0). Далее рассматриваются небольшие отклонения угловой скорости от этого начального положения и все решения вычисляются либо через RK4, либо RK45.

## 
В функции show_angles(solutions) строятся графики phi1(t), phi2(t) для разных начальных данных, печатается максимальное относительное отклонение от исходной траектории.
##
В функции show_pendulum_move(solutions) происходит анимация маятников для разных начльных данных.
