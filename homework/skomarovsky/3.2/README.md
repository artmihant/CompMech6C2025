# Beam 2

Python‑скрипт для:
- расчёта нелинейной консольной балки
- построения диаграмм нагрузка-прогиб
- сравнения линейной и нелинейной моделей балки

Файл: `beam_2.py`

## Возможности
- Расчёт нелинейной консольной балки с помощью методов стрельбы и Ньютона
- Построение диаграмм нагрузка-прогиб

## Модель
Рассматривается задача об изгибе нелинейной консольной балки. Балка нагружена мертвой силой F, приложенной
к свободному концу балки. Балка рассчитывается по теории Кирхгофа, т.е. стержень считается нерастяжимым и
деформации сдвига не учитываются. В таком случае уравнение изгиба балки имеет вид:

x'(s) = cos(θ(s))
y'(s) = sin(θ(s))
θ'(s) = (x(l) - x(s)) * F / k3

k3 = EI - жёсткость на изгиб балки, x, y - координаты точки на ней, θ - угол поворота сечения балки в точке s, s - лагранжева координата вдоль балки.

После обезразмеривания и дифференцирования последнего уравнения по s получаем ОДУ второго порядка:
θ''(s0) = A1 * cos(θ(s0))
A1 = -F/k3 - безразмерная нагрузка, s0 - безразмерная лагранжева координата, вдоль балки меняющаяяся от 0 до 1.

Граничные условия:
θ(0) = 0
θ'(1) = 0

##
В функциях shooting_method_newton и shooting_method_bisection реализованы методы стрельбы с использованием метода Ньютона и метода бисекции соответственно:
краевая задача сводится к задаче Коши с неизвестным начальным значением θ'(0), которое находится итерационным методом.
Функция solve_linear_theory выводит аналитическое решение задачи для линейной теории изгиба балок.

На первом графике изображены балки в деформированном состоянии для нелинейной и линейной теорий изгиба. Видно, что
линейная балка не сохраняет длину, т.к. не учитывает перемещения по горизонтали. В терминал выводится "Beam length verification" -
сравнение длины нелинейной балки до и после деформации, видно, что нелинейная теория сохраняет длину даже при больших нагрузках.

На втором графике произведено сравнение скорости сходимости методов Ньютона и бисекции для решения краевой задачи.
Метод Ньютона демонстрирует квадратичную сходимость, в то время как метод бисекции - линейную.

На третьем графике сравниваются перемещения свободного конца балки в нелинейной и линейной теориях изгиба:
в линейной теории это только вертикальное перемещение, в то время как в нелинейной теории учитываются оба компонента перемещения.

На четвёртом графике показана диаграмма нагрузка-прогиб свободного конца для нелинейной и линейной теорий изгиба балки.
Видно, что при малых нагрузках обе теории совпадают, однако при увеличении нагрузки нелинейная теория показывает значительно меньший прогиб. 
Решения полученные методами Ньютона и бисекции практически совпадают.
