# Моделирование полета снаряда от Земли к Луне

Этот проект реализует численное моделирование траектории полета снаряда от Земли к Луне с использованием методов стрельбы и Ньютона для подбора угла запуска.

## Описание программы

Программа решает задачу трех тел (Земля-Луна-снаряд) и находит оптимальный угол запуска снаряда с поверхности Земли для достижения Луны.

### Основные особенности

- **Физическая модель**: Учет гравитационного взаимодействия между Землей, Луной и снарядом
- **Методы подбора начального угла**: 
  - Метод стрельбы (бисекции)
  - Метод Ньютона
- **Численные методы**: Метод Рунге-Кутты 4-го порядка для интегрирования уравнений движения

## Физические параметры

- Гравитационная постоянная: `G = 66.743e-10 м³/(кг·с²)`
- Масса Земли: `mE = 5.9736e24 кг`
- Масса Луны: `mL = 7.36e22 кг`
- Масса снаряда: `m = 1000 кг`
- Радиус Луны: `1737000 м`
- Начальная скорость снаряда: вторая космическая скорость
