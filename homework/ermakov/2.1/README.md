# Double Pendulum

- реализова класс `DoublePendulum`, который инкапсулирует в себе логику и формулы для двойного маятника
- с помощью метода RK45 происходит численное решение задачи, для чего используется пакет `scipy.integrate import solve_ivp`
- в работе продемонстрировано несколько маятников при разных начальных условиях: разные углы и угловые скорости
- сделана визуализация и проведено сравнение значений углов маятников
