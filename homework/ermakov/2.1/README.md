# Double Pendulum

Движение двойного маятника описывается системой дифференциальных уравнений:

```
(m1 + m2)*L1*alpha1'' + m2*L2*alpha2''cos(alpha1-alpha2) + m2*L2*(alpha2')^2*sin(alpha1-alpha2) + (m1+m2)*g*sin(alpha1) = 0

L2*alpha2'' + L1*alpha1''cos(alpha1-alpha2) - L1*(alpha1')^2*sin(alpha1-alpha2) + g*sin(alpha2) = 0 
```

В программе (написанной на языке python) реализовано численное решение и визуализация двжиения двойного маятника. Конкретно: 
- реализован класс `DoublePendulum`, который инкапсулирует в себе логику и формулы для двойного маятника
- с помощью метода RK45 происходит численное решение задачи, для чего используется пакет `scipy.integrate import solve_ivp`
- в функции `CreateAnimation` происходит анимирование движения маятника и изменение углов этого маятника
- в работе продемонстрировано несколько маятников (5 штук) при разных начальных условиях: разные начальные углы и угловые скорости
- сделана визуализация и проведено сравнение значений углов маятников

В результатах работы явно прослеживается хаотичность движения для маятников с большими начальными углами или большими угловыми скоростями. И, напротив, весьма спокойное и периодичное движение маятников с малыми начальными условиями.
