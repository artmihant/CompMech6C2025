## Введение

Данный проект содержит программы для моделирования электростатических полей в двумерных системах с использованием метода конечных разностей. Реализовано решение уравнения Лапласа для двух конфигураций:
1. Параллельный пластинчатый конденсатор
2. Конденсатор с проводящим квадратом внутри

## Математическая постановка задачи

### Уравнение Лапласа

Для электростатики в области без свободных зарядов потенциал φ удовлетворяет уравнению Лапласа:

∇²φ = 0

В декартовых координатах для 2D случая:

∂²φ/∂x² + ∂²φ/∂y² = 0

### Граничные условия

**Тип I (Дирихле):**
φ|Γ = f(x,y)

### Электрическое поле

Напряженность электрического поля связана с потенциалом:

E = -∇φ

Компоненты поля:
Eₓ = -∂φ/∂x
Eᵧ = -∂φ/∂y

## Численные методы

### Итерационные методы

#### 1. Метод Якоби

φⁿ⁺¹(i,j) = [φⁿ(i+1,j) + φⁿ(i-1,j) + φⁿ(i,j+1) + φⁿ(i,j-1)] / 4

**Особенности:**
- Использует только значения с предыдущей итерации
- Легко параллелится
- Медленная сходимость

#### 2. Метод Гаусса-Зейделя

φⁿ⁺¹(i,j) = [φⁿ⁺¹(i-1,j) + φⁿ(i+1,j) + φⁿ⁺¹(i,j-1) + φⁿ(i,j+1)] / 4

**Особенности:**
- Использует уже обновленные значения
- В 2 раза быстрее Якоби
- Последовательный алгоритм

### Критерий сходимости

Итерации прекращаются при выполнении условия:

max|φⁿ⁺¹ - φⁿ| < ε

где ε - заданная точность.

## Описание программ

### Программа 1: Параллельный пластинчатый конденсатор

**Геометрия:**
- Область: [0,1] × [0,1]
- Пластины: y = 0.3 и y = 0.7
- Потенциал: +V и -V соответственно
- Боковые границы: φ = 0

**Математическая модель:**
∇²φ = 0 в Ω
φ(x,0.3) = +V для x ∈ [0.4, 0.6]
φ(x,0.7) = -V для x ∈ [0.4, 0.6]
φ(0,y) = φ(1,y) = 0

### Программа 2: Конденсатор с проводящим квадратом

**Дополнительные условия:**
- Квадрат: [0.35,0.65] × [0.35,0.65]
- Проводящий материал: ∇²φ = 0 внутри
- Граничное условие: φ = const на границе квадрата
- Потенциал вычисляется самосогласованно

**Математическая постановка:**
∇²φ = 0 в Ω\S
φ = const на ∂S (проводник)
∫∂S (∂φ/∂n) dS = 0 (условие незаряженности)

## Результаты и визуализация

### Выходные данные программ

1. **Поле потенциала** - цветовая карта с изолиниями
2. **Векторное поле** - напряженность электрического поля
3. **Линии тока** - траектории силовых линий
4. **Графики сходимости** - сравнение методов

### Физические явления

#### Краевые эффекты
- Усиление поля у краев пластин
- Искажение эквипотенциальных линий

#### Экранирование
- Силовые линии огибают проводник
- Нулевое поле внутри проводника
- Повышение напряженности у краев
